# Historical evidence

These records preserve development revisions, dated measurements, and qualifications.
They were not regenerated during documentation cleanup. Historical commands, client
versions, identities, and response formats are not current compatibility promises.
Use the [current documentation](../README.md) for setup and supported commands.

- [Investigations and milestones](investigations.md): earlier workflows, API formats,
  discovery experiments, and the development timeline. Its initial reproduction
  commands are explicitly adapted to the current example layout.
- [Runtime comparison](runtime-study.md) and [WASM allocator investigation](wasm-memory.md):
  finite Bun/Node evidence. Current Node execution is unsupported.
- [Distribution review](distribution-review.md): the earlier source/package review,
  before the standalone product and current publication plan.
- [Installed/client validation](installed-validation.md): dated saved-credential and
  version-specific native-client observations, not today's copied-runner recipe.
- [Retired deployment validation](deployment-validation.md): removed provisioning,
  automatic registration, and service-management behavior.

Machine-readable measurements remain in `docs/measurements/`. Historical paths in
source hashes and recorded configurations retain their original names. Public summaries
may redact unnecessary local identifiers with an explicit note, without changing outcomes.
The [study scripts](../../scripts/studies/README.md) document reproduction limits.
